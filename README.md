# realtime-autotune-cpp
A soft real-time autotune and pitch-shifting application in C++ using RtAudio, Autocorrelation pitch detection, FFT harmonic analysis, and Overlap-Add additive synthesis. Developed for the Rea;-time Signal Processing course at Grenoble INP - Phelma (supervised by Prof. Olivier Perrotin &amp; Thomas Hueber).
